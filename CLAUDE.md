# WizardsDuel — Notes for Claude

## What this is
A browser-based 1v1 wizard duel game. Each round both wizards secretly pick a Damage, Protection or Dispel spell (rock-paper-scissors), cast it via a short glyph minigame, then the picks are revealed and play out together. Built with vanilla JS/Canvas, no framework. Main logic lives in `js/game.js` (~5700 lines). Character stats and each character's three signature spells are in `characters.json`.

## The Arcana Alphabet

Every spell's casting minigame uses glyphs from a shared 12-symbol alphabet. This was designed deliberately — do not change the symbols without considering the full system.

### The 12 glyphs

| # | Glyph | Unicode | Name | Shape |
|---|-------|---------|------|-------|
| 1 | ϟ | U+03DF | Koppa | zigzag bolt |
| 2 | Δ | U+0394 | Delta | triangle up |
| 3 | ∇ | U+2207 | Nabla | triangle down |
| 4 | Ψ | U+03A8 | Psi | trident / fork |
| 5 | Ω | U+03A9 | Omega | horseshoe arch |
| 6 | ∞ | U+221E | Lemniscate | figure-eight |
| 7 | ☽ | U+263D | Crescent | open curve |
| 8 | ✸ | U+2738 | Octagram | 8-pointed star |
| 9 | ⊕ | U+2295 | Circled plus | cross in circle |
| 10 | ⊗ | U+2297 | Circled cross | X in circle |
| 11 | θ | U+03B8 | Theta | H-bar in circle |
| 12 | Φ | U+03A6 | Phi | V-bar through circle |

**All 12 are text-only — no emoji presentation variants.** Never replace any with a symbol from the U+2600–U+26FF Miscellaneous Symbols block without checking for emoji variants first (e.g. ⚡ U+26A1 looks like a bolt but renders as a colour emoji on iOS — that's why ϟ is used instead).

### Spell glyph assignments (4 per spell)

| Spell | Element | Glyphs | Notes |
|-------|---------|--------|-------|
| Inferno | fire | `ϟ Δ ⊕ Ω` | bolt / rising flame / solar / consuming end |
| Lightning | lightning | `Ψ ∇ ⊗ ✸` | forked strike / descent / impact / burst |
| Ice | ice | `θ Φ ☽ ∞` | crystal / polar axis / frost moon / eternal |
| Arcane | arcane | `Ω ∞ Ψ θ` | cosmos / eternity / spirit / hidden |
| Dispel | dispel | `∞ ⊕ ∇ θ` | eternal cycle / unbinding / descent / dissolution |
| Earth (was Physical) | earth | `Δ ∇ Ψ ⊕` | stone layers / fork / binding — Rockfall minigame (rune stones fall into shuffled spots on a quaking floor) |
| Dark (Elemental rules) | dark | `☽ ⊗ ∇ Ω` | the Necromancy set — Shadow Circle minigame (runes rise from a purple moon circle and orbit it) |

Dispel similarly draws one glyph from each elemental set (∞ from Ice, ⊕ from Inferno, ∇ from Lightning, θ from Ice/Arcane), fitting its role as a universal spell that dissolves any type of magic.

## Minigame difficulty system

Each spell's minigame has three difficulty modes. Difficulty is set globally in `diffName` (`'easy'` / `'normal'` / `'hard'`).

**Pacing (all minigames):** 5 s to watch (`MG_WATCH_MS`), then 5 s to enter (`MG_INPUT_S`). Sequence length comes from cast strength, not difficulty: `spell.tier` 1 / 2 / 3 (inner / middle / outer strength ring) means 2 / 3 / 4 glyphs. The tile-match uses 2 / 3 / 4 pairs. With no tier, a cast uses the middle ring. The shared helpers `mgSeqLen` / `mgSeq` / `mgSpawnInterval` sit just above `launchBuffTileMatch`.

**Ending (all minigames):** every minigame ends through `mgEnd(ok, info, cb)` instead of calling `puzzleFinish` directly, and never cuts straight back to the battle. Failure holds for `MG_FAIL_MS` (1.3 s): the canvas greys out and shakes, the wrong key is crossed out in red, the key that was wanted pulses gold, the slot row shows the rest of the answer, and a FIZZLED banner gives the reason (`wrong` / `forbidden` / `timeout` / `strikes`, see `MG_REASONS`). Phones also vibrate. Success holds for `MG_WIN_MS` (0.75 s) with a gold flash and SPELL WOVEN. During input, glyph games draw the sequence as a row of slots (`mgDrawSlots`) that fill in as you tap. Pass the reason (and the wrong glyph) to `finish(ok, reason, wrongAi)`.

### Inferno (launchPatternEcho) — the reference implementation
The Inferno minigame was redesigned as an animated rising-glyph mechanic and serves as the model for how the new system should work in all spells.

**Watch phase:**
- Red glyphs (noise) rise continuously from the bottom — visual distraction.
- White glyphs (the sequence) rise one at a time, spread evenly across the 5 s watch window, with a coloured glow unique to each glyph and a small order-number badge.
- Every sequence glyph stays on screen for at least half the watch window (`MG_GLYPH_MS` = 2.5 s): the last one spawns at the halfway mark. Glyph motion and fades are time-based (ms), not per-frame, so high-refresh screens don't speed them up.

| Mode | Keyboard | Fixed or random |

### Gale (launchGalePattern, Air) and Tide (launchTidePattern, Water)
Both run on the shared `mgGlyphGame` runner (timer, input, keyboard, slots, `mgEnd`), which takes an element's scenery and motion (`drawBg` / `drawWatch` / `drawInputBg`), keyboard colours and canonical word. New glyph minigames can use it instead of copying the Inferno code. Gale: sequence runes ride gusts in from the left (`GALE_TRAVEL_MS`), loop once in an eddy mid-screen and blow out right, among sideways-blown noise runes and wind streaks. Tide: runes surface through ripple rings (`TIDE_RISE_MS`), bob on the swell washed sideways for `MG_GLYPH_MS`, then sink, with dark noise runes drifting on the current below rolling wave bands.

### Dispel (launchDispelPattern) — Veil Unravelling
Made harder than the others on purpose (Dispels were too easy). The sequence glyphs are unveiled **one at a time** (fade in / hold / fade out, `MG_GLYPH_MS` each) in **shuffled slots** of a 6-slot inner ring that rotates, with **no order badges** — the order is only shown by when each one appears. Brighter, faster noise rings stay up for most of the watch, and violet **decoy flares** of Dispel's own glyphs appear in the middle ring (2 / 3 / 5 on easy / normal / hard), so the greyed-out keyboard can't rule them out.

## Round flow & RPS redesign

### Round flow
- Every round goes: secret picks → simultaneous reveal → resolution → round-end ticks. That flow is the "ROUND FLOW" section of `js/game.js`. Loop over `PLAYERS` and `gs.pending`; don't hard-code p1/p2 in new round logic.
- Resolution runs in stages (the "ELEMENTAL DUEL" section): every Protection, then every Dispel, then every Damage.
- Each character spell's `el` block in `characters.json` defines it: category, the element sector it takes over on that wheel, kind, middle-ring cost and effect (`sigAtTier` scales the other rings). Keep one signature spell per category + element per character.
- A character's `forbidden` elements (greyed out on its wheel) are a balancing lever: restrict strong characters, never their signature elements.
- Meditate (skip your spell for +3 mana, not two rounds in a row) replaced Classic's Channel. The old "Classic" rules (per-character spell bars, Channel, free basic attacks) were removed.
- **HP is in proportion with tabletop:** every wizard's HP was scaled ×0.6 so a duel takes about as many strikes as at the table; strikes, wards and heals were left alone, and flat HP-sized numbers went with it (Blood Pact 9 HP, KO bounty 12). Games went from about 22 rounds to about 13 (`docs/rps-duel-design.md`, "HP in proportion with tabletop"). Older HP numbers quoted in these notes are from before the cut.
- **Bigger wards, smaller dispels:** wheel wards 25 / 45 / 70 and dispels 10 / 20 / 35 (costs unchanged; `ELEM_CATS`), so a ward is worth its mana but a dispel is still the more efficient answer (about 9–10 power a mana vs 5–6 ward HP a mana); `sealSoak` 10 with it (`docs/rps-duel-design.md`, "Bigger wards, smaller dispels").
- **After changing any numbers, re-run `tools/balance.html` and keep every character within ±8% of 50% with the Normal AI.**
- The agreed Damage / Protection / Dispel design, and the phases still to build, are in `docs/rps-duel-design.md`.

### Timers: wards, buffs and curses
- **Wards** follow the tabletop rule: no round timer, a ward lasts until it runs out. Like the tabletop ward's 1 wink a round, it loses a flat `ELEM_WARD_WEAR` (4 HP) at every round end, and strikes, ticks and dispels wear it too (`ELEM_WARD_ROUNDS` 0, `ELEM_WARD_DECAY` 1). Eldrin's Ward (`holdWard` on its effect) stops the round-end wear.
- **Most buffs have no timer** either (`untimedBuff`: `addEffect` sets `rounds:null`): a buff lasts until a Dispel strips it, a "next strike" buff until it's used. The untimed ones: the armour (War Paint, Stonesoul, Iron Patience, Frost Armor, Dragon Scales), Counter, Arcane Weave, blades and the "next strike" buffs (Empower, Galvanize, Foresight, Infernal Mantle). `BUFF_TIMERS` true gives every buff its `rounds` back.
- **Timed buffs** (`timed:true` on the effect) keep their `rounds` and show them on the status tag: the ones that pay out every round (Regen, Simulacrum, Danse Macabre), whose value would grow without limit; the short bursts (Frenzy, Blink, Vanish); and Eldrin's Ward, whose `holdWard` would otherwise freeze his ward's wear for good.
- **Curses keep their timers.** Permanent curses (tabletop-style, until cleansed) were tried and rejected: income drains starved the mana to cleanse them, and even a hand-picked list left the roster at 40–58%.
- **Arcane unweave rider:** takes a round off a timed buff and frays an untimed one (newest, or all from the outer ring; `ELEM_UNWEAVE_FRAYS` 2 frays unravel it, 🌀 on the status tag). The AI leans harder on dispelling untimed buffs (`buffPull` in `elemAIChoose`).
- Why untimed buffs work (sim, Normal AI): with timers, armour lasted about 2.5 rounds and expired 60–70% of the time; untimed it lasts 4–5.5 rounds and 75% end to a Dispel, so a Dispel takes over the timer's job. The untimed armour was cut to match: War Paint 33→15%, Stonesoul 35→25%, Iron Patience 30→22%, Frost Armor 30→17% / 4→3, Dragon Scales 25→12% / 4→3; Regen and Simulacrum cost 3, Divine Heal 5, Arcane Weave 3. Last balance run after the split: 47.0–54.5%.

### Strikes and what stops them
- `strikeResolve` decides every strike, in order: Vanish (miss), dodge (Blink), Foresight (a charge), then vulnerability and resistance.
- **Minion strikes are strikes** (`MINION_STRIKES_ARE_STRIKES`): each round-end minion strike goes through `strikeResolve`, so Vanish, dodge, Foresight, resist and vuln meet it. It's a physical blow (`dmgKind:'physical'`): a Guard blocks it (no counter), Ironskin soaks it, a ward doesn't stop it. Retaliation (Counter, Frost Armor, a ward's "strikers take") and element riders don't.
- **Foresight** (Aurelia) is used up: it blocks 1 / 2 / 3 strikes by ring (`charges` = tier, set in `sigAtTier`, ×n on the status tag). It also blocks a damage-over-time tick (`dot` effects) at round end, using a charge (`foreseeBlock` in `elemTickEffects`); Agony-type curses aren't blocked. Cost 4 at the middle ring (2 / 4 / 6 by ring).

### Ponder's Vanish
- **Vanish** (cost 2; 2 rounds, 1 / 2 / 3 by ring; `timed:true`) isn't used up: while it lasts every strike at him misses, minions' too (`absorbNext` with `keep:true`, checked first in `strikeResolve`).
- **No striking from hiding:** if he picks a Damage spell, `revealVanished` drops the Vanish as the round's picks resolve (in `resolveSimRound`, before any stage), so he's exposed that whole round.
- **Nothing can lay hands on him either:** a Grapple at a Vanished wizard grasps at nothing (`executeAction`).
- **Curses can't find him** (`VANISH_STOPS_CURSES`, `isVanished`): a curse aimed at a Vanished wizard does nothing. Curses already on him still work.
- **It works like a seal** (`VANISH_TAKES_DISPEL`, in `elemDispelHit`): a dispel at a Vanished wizard only strips the Vanish (Greater too), leaving his ward and other buffs.
- **AI:** foes barely strike a Vanished wizard, don't curse one (`aiSigSensible`) and lean toward dispelling it. Ponder plays combo lines (`aiComboPick`, `COMBO_LINES`): cleanse under Vanish, Vanish when a foe has a strike boost up, and strike in Vanish's last round (`hideStrike`, since a foe facing a Vanish rarely picks a strike). The lines tried and left out are listed above `COMBO_LINES`.
- **HP 69 here** (main's 84 → 80, made before the ×0.6 HP scaling; this branch's Ponder was already 69 when it merged main's Vanish changes). After that merge: Ponder 51.6%, roster 44.8–55.6% (40 games a matchup); encounters Patrol 50.0%, Skirmishers 47.5%, Warband 46.4%. On main before the merge: Last run: Ponder 50.2% (78: 49.7%, 76: 47.6%), roster 45.7–57.3%; after merging main, 51.6% (roster 45.3–57.3%). His worst matchups (Durin, Mordant, Skadi) beat him by attrition and curses, which Vanish can't stop.

**Actions and Magic** (plan of record in `docs/rps-duel-design.md`, "Plan of record: Actions and Magic"; groundwork for RPG fights against non-wizards). Everyone has three free **Actions** (`ACTIONS`): ⚔️ Attack, 🛡 Guard, 🤼 Grapple, in the centre of the Damage / Protection / Dispel wheels (`.whub` in `buildWheelSvg`, `castAction`). They cost no mana, need no minigame, always go off (`payForAction`; `action.act`, `executeAction`) and **last only the round they're made** — melee, not magic; nothing is drawn as a bubble. They answer each other (`ACT_RULES`, read from `gs.roundActs` via `roundAct` / `isGuarding`): Attack vs Guard is blocked and the guard counters for its own atk (`strikeResolve` miss `'guard'`, counter in `strikeMiss` for `o.melee`); a Guard also blocks any physical strike aimed at it that round (no counter); Grapple vs Guard lands in full; Attack vs Grapple hits ×1.5 and the grapple fails; otherwise Attack hits for atk and Grapple for half. Stats: `phys:{atk}` in `characters.json` (`physOf`; `PHYS_DEFAULT` 4, brutes 5–6, slight wizards 3) — most wizards are poor fighters and prefer magic. Damage is magical or physical (`strikeKind`: `dmgKind:"physical"` on a spell or tick, else magic; minion blows always physical). **Every element is magic, Earth included** (Physical became Earth: id `earth`, 🪨; bans are magic only); every ward stops magic only (`wardKind` is always magic). Lasting physical protection is a spell: **Ironskin** (`SKIN_DEFAULT`: 2 mana, soaks 20 blows, plus **upkeep**: `SKIN_UPKEEP` 1 mana at every round end after income, or it fades, `skinUpkeep` in `tickRound`; so against a wizard who casts it's rarely worth it, and against fighters and minions it pays. A character's `skin` overrides it: Sylvara's Barkskin 1 mana / 15, Durin's Stoneskin 3 / 30, which left his wheel; his Earth Protection sector is now **Bedrock**, an Earth ward of 40 for 7 mana with `holdWear`: it never wears at round end (`sigHoldsWear` in `tickRound`'s wear, kept when a plain Earth ward tops it up), about 9% of his picks, Durin HP 65, 49.5%), a button under the Protection wheel (`#wheel-skin`, `castSkin` → `executeSkin`, action `skin:true`). It's a `skin` buff (dispellable, untimed; recasting refreshes it) that `soakSkin` drains in `elemIncoming` for physical damage after minions; physical ticks find it too. Its look is a tint with a sweeping band of light over the sprite (`drawSkinSheen`, `drawSprite`'s `skin`: `{col, alpha, shine}` from the skin; works on stills and on spritesheet frames), not a bubble: Ironskin steel grey, Barkskin dark brown with almost no shine, Stoneskin stone grey. **Layered wards** (`docs/rps-duel-design.md` "Layered wards"; switches in `WARD_RULES`):
- **Top-up:** recasting a layer's element tops it up (`wardBoostTo`: +the cast's HP, up to `boostCap` 1.5 × it); it keeps its `wardSig`. Blink's side-ward never boosts or layers (`raiseWard`'s `noBoost`). Pass a signature ward's id as `raiseWard`'s `sig`; don't set `wardSig` after.
- **Layers:** a new element goes on over the ward, up to `layers` (2). The outer layer is the old single-ward fields, so "the ward" everywhere means the one you'd hit; the layers beneath are `st.wardInner` (innermost first).
- **Never clear a ward by zeroing its fields:** use `breakWard` / `clearOuterWard` (the next layer steps out) or `clearAllWards`, and `wardTotal` / `wardLabel` for the whole stack.
- **Hits:** strikes spill through layers. A lesser dispel stops at the layer it breaks; a Greater one carries through and (`dispelStrips`) strips buffs if it breaks a 2+ stack. Every layer wears at round end.
- **Seals** (`seals`): 🔒 Seal Ward is the Protection wheel's self button (like Cleanse Self on Dispel), a Protection pick with `self:true` (`isSeal`, `SEAL.cost` 1, `executeSeal`). It seals the outer layer (`st.wardSealed`; `sealed` on a layer beneath). Eldrin's `sealAll` seals every layer; `sealCostMod` changes a character's cost. Drawn as a gold Arcana glyph ring (`drawWardSeal`).
  - Sealed layers don't wear. Strikes ignore seals.
  - A seal blocks the whole dispel, Greater included (`sealBlocks`): it breaks the seal and stops, so a sealed ward takes two dispels. A dispel weaker than `sealSoak` (15, a curse's ward hit) doesn't even break it.
- **AI:** tops up below `WARD_BOOST_AI_HP` (25), layers with weight `WARD_LAYER_AI`, seals unsealed wards of `WARD_SEAL_AI_HP` (15)+ HP with weight `WARD_SEAL_AI` (1.0, about 0.4–1.2 times a game), and breaks seals with its cheapest strong-enough ring.
- **Tools:** seal presets and per-run `charMods` are in `WARD_PRESETS`. Compare rule sets with `node tools/ward_compare.js 40 off,boost` (or the **Wards** selector in `tools/balance.html`); add new presets to `WARD_PRESETS` there.
- **Bulwark** (`stackTake` 0.5, adopted): a ward with another layer beneath it loses half as much from each strike (not dispels, `stackDispel:false`). The only switch that made layers pay. Layering tests: `node tools/layer_strats.js` plays a ward strategy (`tools/layer_strats_ai.js`) head to head against the stock AI ("Is layering worth it?", "Adopted: Bulwark 0.5"). Other test switches in `WARD_RULES`: `innerWear`, `dispelMatch`, `layerDiscount`, `stackGuard` / `stackSeal`.

- **Art:** five sheets from the user (generated with ChatGPT), loose pieces on a dark background, not grids: `sprites/ruins/tileset_source.png` (town: ground, houses, props), `tileset2_source.png` (river: side-on bridges, canal walls, plank and grate tiles, docks cargo, cranes, gallows, carts, purple banners, lamps), `tileset3_source.png` (ground transitions), `tileset4_source.png` (house backs and sides, tavern, chapel, tower) and `tileset5_source.png` (bridges from above). `python3 tools/cut_ruins_tileset.py` cuts them all (hand-checked rects in `RECTS` … `RECTS5`, background flood-filled out, props trimmed) into `ruins.png` … `ruins5.png` (256-colour atlases) + `.json` (name → `[x,y,w,h]`). `load()` merges them into one name space, `rects[name] = [x,y,w,h,atlasIndex]`, so piece names must be unique across sheets. **Atlases load per map:** every sheet's `.json` is read at start, but only the `CORE_ATLASES` images (ground and loot); `enterMap` awaits the sheets that map's pieces and ground letters use (`atlasesFor`, `GROUND_PIECE`) before `setupMap`, and `prefetchAround` fetches the maps its exits lead to (and their sheets and palettes) in the background. Drawing skips a sheet that hasn't arrived; `quarterTile` doesn't cache one. Add new sheets to `ATLAS_NAMES`. `--sheet N` cuts one; `--preview out.png` draws a labelled contact sheet. The stone wall/floor frames, stairs and scaffolds aren't cut. Prompts that worked for new sheets: attach the earlier sheets as references, ask for the same scale (a ground tile about 100 px, a cottage about 220 × 265), a flat #101217 background, no labels or dividers, 16 px gaps.
- **Maps are data** (step 1 of the world plan): `maps/<id>.json` (ground-kind letters per row, placed pieces, lore, spawns, exits, invisible `blocks`, night `glows`; format in the comment on `toJSON` in `tools/mapgen/builder.js`), built by `node tools/build_maps.js [id]` from the generators in `tools/mapgen/` (`MapBuilder`: `fill`, `place`, `tryPlace`, `placeBridge`, `edgeWoods`, `scatter`, `wallRun`). Re-run it after changing a generator or re-cutting the tilesets. What each piece is (footprints `FOOT`, `LIGHTS`, bridge decks `BRIDGE`, `T`, `PS`, `rng`) is in `js/explore_pieces.js`, loaded by both the game and the generators. `js/explore.js` picks each tile's drawing from the map's seed at load (`setupMap`), so the files hold only kinds.

- **Counters are tiddlywinks:** HP, mana and wards are whole counters. HP is capped at 12 (`RULES.maxHp`) so both players can share one colour of 25 health winks; mana and ward stay at 20 (`RULES.max`).

## Visual effects
Keep VFX: when changing or removing a spell, keep its look. Every spell's visual is in the "VFX LIBRARY" section of `js/game.js`:
- `SPELL_VFX[spellId]` is each signature spell's own look. `self` plays when cast on yourself, `hit` when it lands on the target, and `delivery` handles lunges and volleys.
- `ELEM_IMPACT_VFX` holds the plain element strikes; `TICK_VFX` / `MINION_VFX` the round-end ticks; `VFX` the shared reactions (ward block/shatter, dodge, dispel, retaliation, …).
- Arcane strikes (wheel and signature, unless the spell has its own `delivery`) go through `elemStrikeVolley`: the strike is resolved once up front (`strikeResolve`: dodge, Vanish, vuln, resist), then the damage arrives as a volley of pulsating blue orbs (`spawnArcaneVolley`, drawn as the `arcaneOrb` projectile), one 5-HP hit per orb (`ARCANE_ORB_DMG`, last orb takes the remainder), fired `ARCANE_ORB_GAP` ms apart, each on a parabola with a random peak height (`spawnProj`'s `arc` option). A shared `wear` object makes a ward wear exactly as from one big hit. Riders (mana burn, lifesteal, DoTs, arcs, retaliation) run once in `strikeFinish` after the last orb. A Deathless save (no character uses it now) or knock-out ends that target's volley, so splitting never changes the total. Other elements use `strikeOne` (resolve → `strikeChunk` → `strikeFinish` in one go).
- Counter's retaliation (Eldrin, a Lightning buff) is a charged electrical arc from his ward bubble (or the gold Counter ring with no ward) to the striker (`counterArc` → `spawnCounterArc` / `tickCounterArcs`, called from `strikeFinish`): a short pause so the strike that set it off is seen (`COUNTER_WAIT_MS`), sparks crawl over the bubble and gather into a ball on the striker's side (`COUNTER_CHARGE_MS`), then a forked bolt arcs across (`makeArcBolt`) and the damage lands with it. It holds the round with `holdFx(ms)` (`gs.fxHold`, which the tier runner's `next()` waits on), so the next action doesn't start until it lands. Other retaliation keeps its `VFX.retaliate` look.
- Fire strikes (plain wheel Fire damage) are a charged fireball: `spawnFireball` swells it in front of the caster to a size set by the damage (`previewStrikeDmg` → `fireballRadius`), fires it across, and the impact is `spawnFireExplosion` scaled by the damage dealt (`tickFireballs` / `tickExplosions`).
- Ice strikes (plain wheel Ice damage) have no projectile: `spawnIceCrystals` crystallises a six-armed snowflake over the target (arms grow from a hexagonal core and sprout side branches; size set by the damage, `iceScale`). It turns slowly, trembles and flares white, then the strike lands and the impact is `spawnIceShatter`: glowing snowflake-arm fragments fly out and fall (`tickIceCrystals` / `tickIceShards`). Ice Lance keeps its own projectile.
- Lightning strikes (plain wheel Lightning damage) have no projectile: `spawnStormCloud` swirls a dark storm cloud together over the target's head (puffs spiral inward, flickering inside as it charges; size set by the damage, `stormScale`), then it discharges: a jagged, forked bolt (`boltPath` / `makeBolt`, width `boltWidth(dmg)`, more branches for more damage) cracks down into the target and flickers twice as the strike lands, and the cloud breaks up (`tickStorms`). The impact is `spawnLightningImpact`: sparks, a crackling ring and, for big hits, a short quake. Lightning signature spells keep their own looks.
- The fireball and its explosion take a palette (`FIRE_PALETTES`: `fire`, `doom` purple, `blue`). Frederick's Doom Bolt and Blue Fire use them via `SPELL_VFX[id].delivery = {fireball:'<palette>'}`; Blue Fire's blast is drawn 1.7× bigger with a quake. Infernal Gate plays `VFX.gateSlip` as he steps through, he steps back out in a ring of fire (`gateExits`), and Infernal Mantle draws a burning ring at his feet while it lasts (`infernalGate` in `drawWiz`).
- Earth strikes (plain wheel Earth damage, magic; was Physical) are a falling boulder: `spawnBoulder` forms it above the caster's head (earth motes spiral in) at a size set by the damage (`previewStrikeDmg` → `boulderRadius`), heaves it across and drops it near-vertically onto the target (`tickBoulders`). The impact is `spawnBoulderImpact`: rock shards, a dust cloud and a short screen shake (`quake` / `quakeOffset`, applied to the whole scene in `battleLoop`). Earth signature spells keep their own looks. An Attack is a lunge with a spark of impact (`executeAction`); a Guard is a brief stance (a float and a few sparks, no bubble), and a block shows 🛡 Blocked! with a riposte lunge. Ironskin tints the sprite with a sweeping metallic sheen (`drawSkinSheen`).
- Air strikes (plain wheel Air damage): `spawnCyclone` first shoots a gust of wind streaks from the caster's staff to the target (`CYCLONE_GUST_MS`; without it the whirlwind alone looked like an Air ward going up), then spins a whirlwind of wind streaks, motes and kicked-up dust around the target, tightening as it forms; the damage lands at its peak with a shock ring and it blows apart. Water strikes: `spawnWave` raises a translucent wall of water beside the target (caster side) that curls over and crashes on them in spray, with swell lines and foam. Both in `gs.elemFx`, drawn by `tickElemFx`, sized by `elemFxScale(dmg)`; a Drenched wizard drips water there too. Ward orbiters: wind wisps (Air), droplets (Water).
- Dark strikes (wheel and signature, unless the spell has its own `delivery`) have no projectile: a ritual circle of the Dark runes appears on the ground at each target's feet (`spawnDarkRitual` / `tickDarkRituals`), whirls around them fast and slows to a stop, glows white-hot, then burns out in purple embers. The damage lands as it burns (the callback). The old shadow orb projectile and Shadow Circle impact (`spawnShadowCircle`) stay in the library but are no longer used for strikes, as is Mana Burn's blue fire column (`spawnManaBurnFire`).
- Arena backdrops: each character's `arena` in `characters.json` names its home painting in `backgrounds/` (`library` = the gothic library: Eldrin, Sylvara, Aurelia, Skadi, Mary, Ponder, Weizan, Mirel, Thessaly, Fizzwick, Nerissa; `ruins` = the moonlit ruined streets: everyone darker or more brutal). A duel is fought on the opponent's ground (`p2Key`, seat 2 in 3–4 wizard games), like the old procedural backgrounds; `arenaFor(key)` loads and caches the image, all are preloaded with `characters.json`, and a character without `arena` gets `ARENA_DEFAULT`. The plan is a painting per character: add `backgrounds/<name>.jpg` and set that character's `arena`. `drawArenaImage` cover-scales it with its bottom edge on the scene floor, adds an `ARENA_DIM` dark wash and fades into dark bands above and below the scene (`fillSceneBands` is skipped). With no arena (`ARENA_DEFAULT` null and no `arena`), or before the image loads, the old procedural per-opponent backgrounds (`drawBG_*`) are drawn.
- Wizard placement: `wizFeetY()` / `wizSize()` (scaled by `WIZ_GROW`) set where and how big the wizards are drawn; effects that play on a wizard use `wizMidY()` (upper body), not a fixed fraction of `bH`. `drawWiz` squashes its round auras into an upright oval (`AURA_SX` / `AURA_SY`); minions keep the original size.
- Time-based rotations: use `spinAngle(t, periodMs)`, never `Date.now()/n` straight into `arc()` or `rotate()`. Canvas arc angles are 32-bit floats, so an angle of billions of radians collapses and the arc draws nothing (this hid Counter's gold ring and Enthral's swirl).
- Primitives: `spawnBeam`, `lunge`, `spawnManaBurnFire`, `vfxRing` / `vfxFountain` / `vfxDrift` / `vfxDrip` / `vfxPhaseIn`. `drawWiz` draws status auras from `wizVisuals()`.
- Ward orbiters (`drawWardOrbiters`, just above `drawWiz`): every ward has one elemental object per 10 ward HP left (rounded up, max 9) orbiting on three tilted atom-style rings — boulders (Earth), ice shards (Ice), glowing Dark runes, flickering flames (Fire), sparks running along faint wires (Lightning), pulsing blue spheres (Arcane). The far side draws behind the sprite, the near side in front. Slots are fixed, so losing HP just drops the last orbiter. They replace Stoneskin's old fixed three rocks.
- Lifesteal (Malachar's Drain, Necrotic Drain, any strike with `lifesteal`): `VFX.lifesteal(who,tgt,heal)` → `spawnSiphon` / `tickSiphons`, a stream of blood motes torn from the target that arcs across and soaks into the caster (more healing, more motes). Not a fountain on the caster. Blood red by default; a spell can set its own colours with `SPELL_VFX[id].siphon` (Necrotic Drain is purple).
- Dispels and curses that hit a ward never burst or flash: the ward unravels (`spawnWardUnravel` / `tickWardUnravels`, via `VFX.wardUnravel`), with threads of its colour and dispel pink peeling off the bubble and spiralling away. When a dispel breaks the ward, `breakWard(st,x,true)` shows UNRAVELLED! and a bigger unravel instead of the shatter burst.
- Wards and buffs phase in (`vfxPhaseIn`: motes fade in and settle inward; `auraFade` grows the ward bubble in) — never use `spawnParts` bursts or `flash` for them, since a burst on yourself reads as taking a hit.
- Portraits: `portraits/<key>.png` is the full-size source art and the game never loads it. The UI uses `portraits/small/<key>.jpg` (a 256×256 close-up of the face, for every small icon) and, for the character detail panel, `portraits/medium/<key>.jpg` (whole portrait, 720 px). Each face crop is set by hand in `FACES` in `tools/make_portrait_thumbs.py`. The icons are plain hi-res crops of the source art (no pixelating). Daveron's portrait is the full artist painting (1122×1402); his sprite was cut from a mock-up screenshot (background removed with rembg u2net plus hand-tuned mask fixes) — a cleaner source from the artist should replace it. Frederick's 703×768 sprite was cut from a mock-up with a baked-in checkerboard (flood-filled out from the edges, plus the enclosed checker holes in his staff wheel); his flame is purple in the sprite but green in the portrait. After adding or changing a portrait, add or adjust its `FACES` entry, run `python3 tools/make_portrait_thumbs.py`, and check the crops with `--preview out.png`.
- Battle sprites: each character's `sprite` in `characters.json`. Either an old 192×320 spritesheet (`mage-*.png`, 48×64 frames, facing left) or a single full-body still named after the character key (`sprites/<key>.png`, 512×768, facing right). `drawSprite` handles both; stills are sized by height and keep their aspect ratio, so a wide pose can use a wider canvas (Daveron is 607×768 so his flame and staff fit at full height). An optional `spriteHeight` (e.g. Durin, a dwarf, and Zakkit, a ratman: 0.72; Gretch, a hulking troggoth: 1.5, with `spriteHeightMulti` 1.2 replacing it in 3–4 wizard games) and `spriteWidth` (Durin: 1.2, stretches the sprite sideways) scales that character's battle sprite, feet staying on the floor (`seatSpriteHeight`). Its auras, ward and the effects aimed at it shrink too: `wizSize(at)` / `wizMidY(at)` take a seat or an x position (nearest seat), and `vfxCtx` gives `cy` / `ty` for the caster's and target's heights. Use those, not the no-argument forms, for anything that plays on a wizard.
- Skeleton summons (Valdris's Raise Dead): `sprites/skeleton1.png` / `skeleton2.png` / `skeleton3.png` for the inner / middle / outer ring (the ring only changes how many rise, 2 / 3 / 4): a ragged skeleton, an armoured spearman and a crowned wight. `drawSkeletons` draws them after Valdris and his front ward orbiters, so they stand in front of him and the ward; up to five go in `SKELETON_SLOTS` (front row of three, smaller back row of two), sized from his drawn height (`SKELETON_HEIGHT`). Same format as the character stills (facing right, feet at the bottom edge); height by tier is `SKELETON_HEIGHT`. A missing file falls back to the bone circle. Each summon effect records its `tier`, and `syncMinionVisuals` passes it to `drawWiz`.
- Bone Totem (Gretch's `bonetotem` totem minion): `drawBoneTotem` draws `sprites/bonetotem.png` (pixel-art still, feet at the bottom edge) planted on the floor on the foe's side of him, in front of his sprite and ward (`BONE_TOTEM_HEIGHT` / `BONE_TOTEM_DX`, in units of his own drawn height, so it follows his `spriteHeight`). It rises in with `auraFade`, sways and pulses green; a missing file falls back to a skull circle.
- `js/legacy/` holds code the game doesn't load: the original Classic spell code (`classic_spells.js`, with every effect in context) and the old puzzle minigames, including Mana Burn (`puzzles_legacy.js`).

## Cache-busting
Every script and the stylesheet in `index.html` carry a `?v=` number. **Bump a file's number whenever you change the file** (and on a merge, bump every file either side touched): a browser that cached the old copy under the same number runs it against newer code, which broke New Game after the University Year merge ("Couldn't load the map", a stale `explore_pieces.js` without `scaleOf`). Explore's JSON data (maps, atlases, figures, toppers, characters, fighters) is fetched with `NC` / `{cache:'no-cache'}` so it revalidates. The map loader's error now shows the underlying message.

## Placeholder art
When new content uses stand-in art (another character's sprite, a recolour, a borrowed tileset), add a row to `docs/art-prompts.md`: what stands in now, the file the real art goes to, the code that points at it, and a ready-to-paste prompt.

## Symbol safety rule
Before adding any new Unicode symbol to the game, check it is **not** in the emoji presentation set. Risky blocks: U+2600–U+26FF. Safe blocks: Greek (U+0370–U+03FF), Mathematical Operators (U+2200–U+22FF), Dingbats (U+2700–U+27BF, mostly safe). When in doubt, append U+FE0E (text variation selector) or pick a different symbol.
